Drop a .ttf/.otf here (e.g. a free Google Font like Montserrat ExtraBold) and point your style at it:

    "caption": { "font": "Montserrat ExtraBold", "font_file": "fonts/Montserrat-ExtraBold.ttf" },
    "carousel": { "font_file": "fonts/Montserrat-ExtraBold.ttf" }

`font` must be the font's family name as the font file declares it.
