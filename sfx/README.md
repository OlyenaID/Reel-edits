Drop your own sound effects here (.mp3, .wav, .m4a…). The file name becomes the sound's name,
e.g. `cha-ching.mp3` → use `"sound": "cha-ching"` in edit.json or pick it in the studio's Sound tab.

Built-ins (generated on first use, nothing to download): pop, click, whoosh, ding, boom, rise.
A file here with a built-in's name replaces it.

Free sources: Pixabay sound effects, freesound.org (check each file's licence), YouTube Audio Library.
